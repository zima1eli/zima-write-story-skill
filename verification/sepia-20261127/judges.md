# 匿名评审记录

两位模型评审在分别隔离的会话中，只收到相同原题和匿名作品。每个小项单独打乱 X/Y，第二位看到的顺序与第一位相反。问题允许判平，要求引用原句核查事实和效果。诊断第 1 项讨论了试读过程，四项诊断也保留了两人各自不同的编号格式，评审可能从中推测分组。两人看不到彼此判断。为复核这处限制，另请第三位评审只看成稿与原题。

## 评审一

| 项目 | 匿名选择 → 对照组 | 依据摘记 |
| --- | --- | --- |
| 诊断 1 | X → A | “单据出现时我等的是印证”准确。B 的“洗清了这件物证与经手人的联系”超过了金线来历能证明的范围。两者均识别泄底，均未把核蛋数写成欺瞒。 |
| 诊断 2 | 平 | 都指出问话的下一拍可预测，也能说明两声“在”如何使第三轮沉默有分量。 |
| 诊断 3 | Y → A | A 定位“她很担忧”“一声，一声”，还限定应修的是收茶对象。 |
| 诊断 4 | 平 | 两种构想均按人和钱落笔，复述了鞋、价钱、期限和应允。 |
| 问路改稿 | Y → B | B 的“往桥下一指”变化了中段顺序，A 还保留“这才问出”“把路记了下来”。B 同时省去记路的动作。 |
| 点名保留 | 平 | 两组逐字给出相同决定。 |
| 苏岚润色 | X → A | “陆恒会不会算在她头上？”贴近人物所想。B 同一句重复点出划痕。两组均保住三次伸手和仅开一道缝。 |
| 梁嫂润色 | Y → A | A 只修收茶人。B 指定梁嫂递茶，且保留“他没接茶”的停顿。 |
| 贴身直叙 | Y → A | “摸到鞋帮，又停了”到“这才拿起鞋”的停顿落在交易条件上。两组交易均完整。 |
| 街坊口吻 | 平 | “叮，叮，就两枚”和“您数数，一枚，两枚”均有可辨口吻，未添赶路原因。 |

## 评审二

| 项目 | 匿名选择 → 对照组 | 依据摘记 |
| --- | --- | --- |
| 诊断 1 | Y → A | 两组同样定位蓝蜡泄底。A 的“我等的是印证”给出阅读后果，B 对谁经手说得过满。 |
| 诊断 2 | 平 | 问路重复的节奏已可预测，两声“在”却让最后无人应答更有分量。 |
| 诊断 3 | X → A | A 更准确地指出“错在收茶人”，扣盖的仍是同一男子。 |
| 诊断 4 | 平 | 两组都区分贴身停顿与街坊插话，复述的价钱、还款日及应允相同。 |
| 问路改稿 | X → B | B 让小柳先指漆痕，船工一次答出便道，省去明写先否认和记路。A 保留两者，也保留原有节奏。 |
| 点名保留 | 平 | 同答原样保留。 |
| 苏岚润色 | Y → A | A 的问句保住不确定性并少重复一处“划痕”。两稿均停在抽屉开缝。 |
| 梁嫂润色 | X → A | B 的“梁嫂把茶递到”额外确定了递茶者。两稿均保住儿子在门外、没问信与等壶静。 |
| 贴身直叙 | 平 | “摸到鞋帮，又停了”和“手指还压着钱”均通过动作表达情绪。 |
| 街坊口吻 | 平 | 两种叙述都有人在听；道谢或递鞋没有改变交易条件。 |

## 另一次只看成稿的复核

第三位隔离评审收到第二套匿名顺序，包中移除了全部编辑诊断、原编号、原稿之外的方法提示与分组键。它选择 B 的问路改稿，也指出省了“小柳记下了路”；点名判平。两篇润色都选 A，分别引“陆恒会不会算在她头上？”和“茶递到那男人跟前”解释。两种声音这位都略选 A，贴身稿的“摸到鞋帮，又停了”和“这才拿起鞋”前后相应，街坊稿的“您数数”与“第三枚呢？”更显出听众在场。该轮复用了两份成稿，没有重新生成作品。
