## 独立边界题一：全知叙述与熟悉地点

不需要每次先列感官证据再说修伞铺的名称。按本题的独立前提，本书采用全知叙述，而且人物早已熟悉这个地点；全知叙述允许范围和人物既有知识都能支持直接命名。可以按该书风格直接说修伞铺，不必反复写招牌、伞架、气味，再让人物“推断”它是一家修伞铺。

## 独立边界题二：把第三次开缝改成递出原件

不能作为润色直接接收，应退回并恢复到只拉开一道缝。

“把抽屉拉开一道缝”只改变抽屉的开合程度；“拉出原件递给陆恒”至少新增取出和交付两个动作，把原件从抽屉中转移到交付状态，也改变陆恒获得证据的机会与本段事件进度。递给他本身还不足以证明他已经读懂内容，不能再顺势认定他已知道旧划痕，但它已经违反附件明确的“尚未取出、尚未展示”限制。

另外，原句的结果只有一道缝，承接前两次未完成动作，体现迟疑的逐步松动；改成直接递原件，会把这项细微递进提前收束成实际交接。句子更顺或信息更完整都不能抵消这笔事实代价。

依据是表达模块后置润色第 7 条和 polisher 契约第 1、5 条：已发生的信息交接可以澄清，新发生的交接或事实变化必须作为结构性候选交主 agent 裁决。本任务的明确范围已经排除该动作，所以当前应直接定点还原，不靠追加说明合理化；若另有后续改写授权，再单列结构性修改并对新版本审查，不能在本次润色中先行入账。
