# 第二章 门合上时

苏岚从打开的工具箱里拿出螺丝刀，起身回到门边。还是刚才那处，门一动，铰链边角便跟着晃。她把门推开些，一只手扶稳，低头看原来的固定位置。

陆恒站在旁边，给她留着地方。

螺丝刀的尖头抵上去，苏岚转了半圈，又停下。铰链还歪着一点，她松回些，用扶门的那只手慢慢调整。边角贴平了，才重新拧紧。

她没有立刻放手。扶着的手掌往回收了一点，看看铰链，再收一点。固定处没有跟着门晃。她把螺丝刀搁在箱沿，握住门把手，先慢慢合上，又拉开。

那一声没响。

她再试了一回。门到了原来会响的位置，仍旧平稳地过去。苏岚低头看过固定处，才往旁边站开。

“你来试试。”

陆恒接手，把门往里带。他没有马上说话，又拉开，手停在把手上，将门推合了一次。

苏岚原本已经弯腰去拿工具，听见门动，又直起一点。螺丝刀就在箱沿，她没拿，等着。

陆恒看了看铰链，松开把手。

“可以了。稳了，也不响了。”

她这才蹲下，把螺丝刀放回箱里。

“那就按原来约定的办。”陆恒说。

“好。”

两人把交接事项核清，陆恒按原约定退还押金。苏岚确认收到了押金，又核对了一遍。

“收到了，押金结清。”她说。

“铺面也核对好了。”

苏岚点了点头，没有再把交接单拿出来。那张纸还在另一侧衣袋里，隔着衣服压在她腰边。

她将抽屉里余下的工具收进自己的箱子，放到一半，重新排了排位置。刚用过的螺丝刀也压稳了，箱盖落下来，没有碰到工具柄。她扣好搭扣，握住提手站起来。

空着的手伸进衣袋，摸到铺面钥匙。她把钥匙拿出来，递向陆恒。

陆恒张开手。

钥匙落进他掌心，苏岚松开手指。她看见他将钥匙握住，便提着工具箱走到门外。

身后的门动了。苏岚回过头，陆恒正把门带回来。门从她身侧缓缓合上，原来那声短而涩的响动，没有再来。
