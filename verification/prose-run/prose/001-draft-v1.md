# 第一章 旧痕

傍晚，苏岚把铺面钥匙从柜台上拿起来，陆恒的手指却停在了柜台边。

“这里，你看看。”

她顺着他的手指看过去。靠门那边一道长划痕，到了末端分成两岔。她把钥匙攥进手心。

“这个不是我弄的。”

“我接回来，总得看清楚。”陆恒的指尖在划痕旁边点了一下，“有要修的，咱们现在说。交完了再找人，就不好办了。”

“我来的时候就有。柜台我一直用着，这道痕我能不知道？”

“你说原来就有，拿什么核对？”

苏岚张了张嘴。她记得那道岔口，擦柜台时抹布经过那里，总会慢下来。但这些仍然只是她在说。她刚想再说一遍“来的时候”，忽然记起，入铺时有张单子，柜台和店里的东西都记在上头，她还签过字。

“有交接单。”她松开攥着钥匙的手，把钥匙放进衣袋，“你等一下。”

工具抽屉拉出来，先露出一排挤在一起的工具柄。苏岚挪开上头两件工具，手伸到纸页和抽屉侧板之间。几张纸被压得很平，她往外抽，纸角碰在工具尖上，赶紧停住，换了只手托着。

陆恒站在柜台那头，没有催她。

她把纸一张张分开。看见自己的签名时，手指停了一下。是这张。她将折起的下半页展开，沿着记录柜台的那一行看下去。

“柜台靠门一侧有长划痕，末端分岔。”

苏岚又看了一眼柜台。纸上的位置，长痕末端的两道岔口，都对得上。她将单子转过去，推到陆恒面前。

“原来签的这张。你看柜台这一项。”

陆恒接住纸，没有立刻接话。他把折痕压平，低头看了一遍，又转身对着柜台看。苏岚的手还压在纸边，等他将目光从岔口移回来，才收开。

“这就对上了。”他说，“这条是原来就有的。”

“我说了不是我——”

苏岚把后半句停住。陆恒将纸递回来，手指已经离开柜台。她低头顺着旧折痕折好单子，放进另一侧衣袋。终于不用再把同一句话说一遍，她的肩膀松了下来。

陆恒走到门边，拉了一下门。门上响了一声，又短又涩。

苏岚抬头。那枚铰链的边角随着门动了一下，她看见了原来松着的固定处。刚才急着核对柜台，她把这件事漏过去了。

“门还有这个。”陆恒说。

她走到门边，手扶住门，把那处仔细看了看。刚才想说的话这时更说不出口了。

“这枚铰链我漏修了。”她说。

陆恒让开半步，仍看着门。

苏岚扶着门等它停稳。“先把它修好，再交店。工具都在。”

“行。修好了，我再试一下。”

她点点头。押金还没有结清，钥匙也仍在衣袋里。苏岚放开门，转身蹲到自己的工具箱旁，把箱盖打开。
