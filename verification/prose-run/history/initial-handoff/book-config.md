# 本书配置

配置版本：`config-v1`。表达版本：`style-v1`。来源版本：`sources/outline.md / outline-v1`，源文件与技能的校验值见 `evidence/source-manifest.json`。

## 来源与总目标

本书标识 `rain-before-stop`；书名《雨停之前》；现代生活短篇；全书只有001—002章。用户要求两章可直接扩写的施工图、适用配套资料、首批交接验收。本次规划覆盖001—002，正文按每章一批执行，当前B01仅001；规划完成不推出全书正文完成。

来源标记约定：`大纲已定`指用户大纲中的规划约束，未来事件尚未发生；`本轮设计`指本轮为可写性补出的安排；`待定`指没有证据的内容；`已接受正文实绩`本轮为空。

## 大纲已定

依据 `sources/outline.md` 的人物背景段、第一章段、第二章段及要求段：

- 苏岚经营修伞铺，即将向房东陆恒交还铺面；她要取回原约定押金，并证明柜台损伤不应由她承担。
- 陆恒担心交接后无人处理修缮，要当面核对。两人都保有合理立场。
- 事件顺序固定：指出划痕 → 苏岚先争辩 → 想起入铺时签的交接单 → 工具抽屉找到原件 → 原件证实同一条旧划痕 → 发现漏修铰链 → 苏岚提出先修门 → 同晚用现有工具修好 → 陆恒试开关并确认 → 按原约定交接并结清押金 → 苏岚带走工具箱、交出钥匙 → 门开合不再有杂音。
- 原件是划痕证据。不能改为证人、照片、临时补签，不能增加伪造证据或阴谋。
- 陆恒读到交接单之前，不知道这条划痕早已存在。
- 第二章结清并完结，不留下第三章预告。

## 表达配置 style-v1

依据：大纲明确要求；没有样章，不声称已匹配任何既有正文声音。

- 第三人称限知，主要跟随苏岚；本轮两章统一跟随苏岚，不切入陆恒心内独白。
- 可以写苏岚的感官、记忆、判断；陆恒立场通过当面说出的顾虑、核对、看纸和试门动作呈现。苏岚对他动机的猜测必须保留为猜测。
- 朴素克制：重动作和具体物件，情绪附着于争辩停顿、递单、收工具；不反复替人物总结道理。
- 对白功能：苏岚分清旧损伤与自己该补的修缮；陆恒要求证据及可验收结果；不一方讲大道理、一方无故屈服。
- 节奏：001争执简短，找纸与核对给足读者辨认时间；002修理保留动作因果，不写成教程；确认之后简明完成结算与移交，用安静的门作余韵。
- 禁区：超自然能力、复杂系统术语、阴谋反转、恶房东审判、突然爱情线、无来源经历与债务、全知揭心、总结式升华。
- 下游默认按 `human-writing` 小说适配润色，并以本配置为约束；不得为了通用润色改变事件顺序、认知、道具及结局。

## 待定、适用性与风险

- 待定但不阻断：押金具体数额、支付方式、铺面地址、租期、工具具体品牌、人物年龄数字。正文不需要填写这些数值；保持“按原约定”“结清”即可。若下游认为某数值承担新因果，应退回上游确定。
- 当前无需要用户决策的阻断项。未确定的身份经历、天气、未来去处不自行扩展；书名不能证明正在下雨。
- 主要风险：把铰链漏修写成旧交接单记载；陆恒提前知道证据；修理未经试门直接结清；提前交钥匙；结尾添加新任务。详见执行包硬门。
