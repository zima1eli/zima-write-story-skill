# 《雨停之前》写作项目

本书标识：`rain-before-stop`。这是从零正文开始的两章现代生活短篇。当前交付为全书两章写作准备及首批开写交接，不含正文。

先读 [当前入口](00-CURRENT.md)，再按唯一当前执行包读取本批材料。下游不用加载上游技能全文。

## 材料入口

- [原始大纲](sources/outline.md)：用户唯一故事来源，v1，原样保存。
- [本书配置](book-config.md)：题材、表达版本、硬约束、设计空间、适用性。
- [全书段纲与两章施工图](planning.md)：v1，含每章技法、材料层与连续性。
- [初始状态与计划变化](state.md)：initial-v1；没有已接受正文实绩。
- [进度与成熟度](PROJECT_PROGRESS.md)：总范围、当前批次、未完成项。
- [本批输入包](packages/input-B01-v1.md)：规划依据，不能作为独立开写入口。
- [首批执行包](packages/execution-B01-v1.md)：B01，仅001；002已具施工图，待首章实绩入账后生成B02。
- [规划审查](reviews/planning-review-v1.md)及[首批交接验收](reviews/handoff-acceptance-v1.md)。
- [读取与版本证据](evidence/source-manifest.json)、[draft落盘核验](evidence/verification-draft.json)、[active最终核验](evidence/verification.json)。

全部规划中的章末、书末状态都是未来约束，不是已发生事实。只有下游写作、润色、审查、必要修复复审并被主审接受之后，才能更新实绩。项目内未编写任何小说正文。
