# 验证用虚构项目：雨停之前

这是一部只有两章的现代生活短篇，用于检验源技能。人物均为虚构成年人。

苏岚经营的小修伞铺即将交还房东陆恒。苏岚希望拿回约定的押金，并向陆恒证明自己没有损坏柜台。陆恒担心交接后留下无人处理的修缮，因此要求当面核对。两人都有理由，不写成恶人对好人的审判。

第一章：傍晚，陆恒指出柜台旧划痕。苏岚先争辩，随后记起入铺时签过一张交接单。她在工具抽屉里找到原件，纸上明确记录了同一条旧划痕，但还发现自己漏修的一枚门铰链。章末她提出先修门再交店。陆恒亲眼看过交接单后才知道划痕早已存在。

第二章：同一晚，苏岚用现有工具修好门铰链，陆恒试开关后确认。两人按原约定完成交接并结清押金。苏岚带走自己的工具箱，把铺面钥匙交给陆恒。结尾落在门开合时不再发出的杂音上，不预告第三章。

要求：第三人称限知，主要跟随苏岚；语言朴素克制，人物对白保留各自立场；无超自然能力、无复杂系统术语、无阴谋反转。事件顺序、旧划痕的证据、门铰链修复、钥匙归属和两章完结不可改变。

当前项目没有正文、配置、状态表或执行包。只提供了这一份大纲。
