# 正文首次选文风的定向验证

本轮在仓库正文源技能上做了独立对话试跑。书和执行包使用虚拟输入，有库场景实际读取本机 Wiki。以下记录对应本次模拟，只验证选风格及短段落交付。

| 输入 | 观察到的动作与输出 |
| --- | --- |
| 修改前，渡口兄妹题材，首章卡要求停航、旧票价、瞒欠条，技法等其余材料齐全 | 有库、无库两次均把主编拟定的口吻当成本轮提案，直接写出开头。可从旧版交接契约与小说表达适配中的“未知风格”条款复核。 |
| 修改后，第三人称限知跟随妹妹，船主退押物并试探谁可作保；有本地知识库 | 实读《动作写完不解释》与《古龙对白的试探与信息留白》，在虚拟包区分全书叙述和本场对白。输出中船主退回怀表，开口问哥哥住哪，妹妹瞒着的欠条没有经由旁白透露给哥哥。 |
| 无库，旧包标为 active，风格只写“生活流，待细化”。小姑娘追邮车取回信 | 首轮用同一场面比较“贴着小姑娘写”和“像街坊讲一件岛上的事”，并请作者选择。独立第二轮输入“我选第二种，像街坊讲”后，以该回复为风格来源重验虚拟包。三句开头先让街坊喊停邮车，再让小姑娘认信，撤信缘由仍保留。 |
| 新会话，库离线，前五章和第六章包沿用作者选定的“街坊口述”v2 | 直接按记录续写。街坊先喊掌柜，掌柜抬眼才看见铜钥匙放回柜台，符合叙述者只能讲本人所闻所见的约束。 |
| 无库、无配置，作者只要求润色两句等待下雪的对白 | 直接处理原句，把末尾改成“我还等着呢”，保留前后两次“等”及人物嘴硬的语气。 |

仓库根目录运行 `python -X utf8 scripts/verify_repository.py --self-test` 可复核打包。定向试跑与全部用例定义分开计数。新增的第 27–29 例保存在正文技能的 [evals.json](<../zima-write-web story/evals/evals.json>)，包含可用库、无库两轮选择和续章复用的重测输入。以上场景未部署到小说项目或实际客户端。
