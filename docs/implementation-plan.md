## 共享接口

- 本书配置记录大纲来源、用户总范围/深度、题材、叙述视角、风格依据、硬约束、可设计空间、待定项和材料清单/实际路径。未知风格不能冒称用户已定。
- 材料按通用必需、内容需要、阶段需要生成；可以合并文件。重要条目标为大纲已定、本轮设计、待定、已接受正文实绩。
- 本批输入包保存规划依据；当前执行包为按最新已接受实绩校准的批次快照，可同文件分区保存。执行包不是独立事实来源。
- 执行包元数据：本书标识、包 ID/版本、章节范围、规划来源版本、事实基线版本、风格版本、状态、生成者及验收证据。版本可用修订号或哈希，不要求特定数据格式。
- 状态：`draft`、`active`、`consumed`、`invalidated`；当前入口指向唯一可执行包。零正文首批由已审规划和初始状态生成，无需虚构上一批报告。

- 草稿变化先是候选，接受后才写入状态；修订使相关旧报告/包失效。恢复记录逐章阶段、正文版本、报告及下一动作。
