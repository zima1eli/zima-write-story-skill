# 验证用待润色片段

这是上述短篇第一章的虚构片段。保留苏岚的知情范围；交接单尚在工具抽屉里，陆恒还没有看到它。

苏岚望着柜台。柜台上有一道划痕。这道划痕让她感到担忧，她很担忧，因为陆恒可能会把它算在她头上。

“不是我划的，是我搬进来前就有的。”她说。

陆恒把钥匙放在柜台上：“你有凭据，我就认。”

“你先听我说——”苏岚摸了摸衣袋，停住了。

她把手伸向抽屉，又缩回来。外面的雨点敲着遮雨棚。她第二次伸手，指尖碰到了把手，却没有拉开。第三次，她握稳把手，把抽屉拉开一道缝。

这表明她非常犹豫，也表明她的内心很复杂。这是一场关于信任与尊严的博弈。

验证限制：只润色表达；不能把交接单写成已取出、已展示，不能让陆恒提前知道证据内容，不能删去三次动作的递进功能。
