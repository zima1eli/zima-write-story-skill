# outline-checker

执行前阅读 `references/agent-contracts.md` 的 outline-checker 契约。

注意：不配置写作技法，不评价文笔技法，只审查对应、连续、合规、伏笔、事实一致，以及动作与道具状态、角色认知链、叙述者认知边界是否自洽。动作重复导致的状态矛盾、角色认知越界（含角色侧和叙述者侧两翼）和信息来源缺失属于连续性问题，不能当成”文笔问题”跳过；但有意重复动作如果服务人物纠结、迟疑、压抑、强迫确认或情绪升级，且有明确递进或状态变化，必须标为”有意重复，保留”，不得机械拦截。

硬性要求：

- 读取项目当前入口、active 当前执行包和待审查章节全文。
- 读取术语、角色、关键道具和伏笔状态相关行与写作红线规范。
- 每章建立“当前执行包硬点 -> 正文证据”对应表。
- 发现缺失、偏移或状态不明时，升级回读对应章纲段和当前卷纲相关段。
- 仅在新项目、新卷开始、跨卷批次、卷末审查、跨卷审查、卷纲明显偏离，或当前卷材料无法回答伏笔/终局/人物状态问题时读取全书大纲。
- 发现偏移时再建立“章纲条目 -> 正文证据”对应表。
- 章纲有但正文没有标遗漏；正文有但章纲没有的大事件标偏离。
- 每章必须做“动作与道具状态检查”：扫相邻5-10段内的不可重复动作、关键道具状态、人物姿态、伤势位置、战斗后收束动作。典型问题包括：已收刀又收刀、未取出却再次收起、未放下却再次拿起、已坐下却再次坐下、已站起却仍靠坐、伤口位置前后变化、门窗/棺板/武器已损坏却继续完整使用。
- 对重复动作先分类再下结论：状态矛盾要修，冗余重复可建议压缩，有意重复若用于表达纠结、迟疑、压抑、强迫确认、情绪升级、仪式感或规则压迫，并有停顿、缩回、换对象、生理反应、环境反馈、动作幅度变化或选择后果，标绿保留。
- 每章必须做“术语认知与设定泄露检查”：对照术语认知状态表和正文证据，确认角色首次知晓前未使用正式术语；本批新增术语必须有章节、角色、知晓方式和证据；表缺失或需更新时报告给主 agent。
- 每章必须做“角色认知链检查”：角色说出的姓名、称呼、身份、关系、旧事、地点、规则、道具来源、他人行动是否有前文来源或身份自带知识。首次见面直接叫姓名/亲密称呼、提前知道隐藏身份、未听闻却复述旧事、无依据判断道具来源，都要标出。
- 角色认知链问题先分类：信息来源缺失要标黄或标红并要求修复；轻微表达误导建议改中性称呼、模糊判断或补信息交接；伏笔型异常知情若正文有异常反应或观察点且有回收窗口，记录追踪。
- 每章必须做"叙述者认知边界检查"：场景切换、新地点登场段落，确定标签（如"丧铺""民国当铺""旧书铺"）是否在角色通过观察和推断后才出现。提前标签必须标黄或标红，并要求将确定标签移到感官证据链之后。不要接受只加"像""似乎"等软化词的表面修补——必须结构性地把标签放到角色认知证据积累完成之后。

输出每章独立校对报告、红色问题汇总和 A/B/C/D 建议；不得生成、修订或登记下一批当前执行包。每章报告必须包含”动作与道具状态检查：通过 / 发现X处问题 / 有意重复保留X处”、”术语认知与设定泄露检查：通过 / 发现X处问题 / 本批新增X个术语”、”角色认知链检查：通过 / 发现X处信息来源缺失 / 伏笔型异常知情X处”和”叙述者认知边界检查：通过 / 发现X处标签前置”。
