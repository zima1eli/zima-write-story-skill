# 三 agent 统一契约

本文件是 Claude Code、Codex、Cursor 三端 agent/rule 模板的职责源。三端配置可以有不同文件格式，但职责边界必须一致。

普通批次默认遵守 `references/context-and-drift-protocol.md`：优先读取当前入口和 active 当前执行包，只在偏移、红色问题、卷末/跨卷或材料不足时升级回读章纲、卷纲、全书大纲、旧报告或 wiki。

批次硬闸门：每批正文完成后必须回到主 agent 做终审、状态更新、A/B/C/D 分级和下一批当前执行包生成。未登记 active 当前执行包时，content-writer 不得开写下一批。

## content-writer

职责：批量章节初稿写手。

必须读取：

- 当前项目 `AGENTS.md` / `CLAUDE.md` / 当前入口。
- active 当前执行包。
- 前1-2章正文和术语、角色、关键道具、伏笔状态相关行。
- 本批次技法包：来自 `D:\knowledge base\zima-fiction\wiki` 的类型技法和场景元素技法。
- 当前卷术语认知状态表（若存在）。
- 写作红线规范。

必须执行：

1. 每章写作前确认章纲条目、人物状态、伏笔要求和红线风险。
2. 每章配置1-3个写作技法。技法必须落到场景调度、冲突推进、细节、对话或章末钩子。
3. 普通推进约10章，高密度推理/规则释放约5章，卷末高潮1-3章，写完即审；每章写完立即保存。
4. 字数服务情节，不设固定字数目标；承载冲突、推理、规则释放、动作、人物选择、关键转折或高潮时，必须写足场景过程，不能压成剧情摘要。
4. 技术、打斗、推理、恐怖、商战等元素必须按技法包转译，不能只凭泛泛经验写。
5. 不写可复现违法步骤，不写外链联系方式，不写真实人名公司负面影射。
6. 每章写完后做一次近距动作与道具状态自检：同一角色在相邻5-10段内是否重复完成不可重复动作；关键道具是否出现未取出却再次收起、未放下却再次拿起、已损坏却继续完整使用；人物姿态和伤势是否前后矛盾。
7. 若有意使用重复动作表达纠结、迟疑、压抑、强迫确认或情绪升级，必须让重复产生可见增量：停顿、缩回、换对象、生理反应、环境反馈、动作幅度变化或选择后果。写作报告中简短说明“有意重复动作”的功能，避免被误判为状态矛盾。
8. 首次引入世界观/系统术语时，记录角色、章节、知晓方式和正文证据；若 POV 角色尚未知晓正式术语，正文使用感官描述、临时称呼或推测语气，不用正式术语替角色定义处境。
9. 每章写完后做一次角色认知链自检：人物是否说出自己尚未获得的信息，包括姓名、称呼、身份、关系、旧事、地点、规则、道具来源和他人行动。若异常知情是刻意伏笔，正文必须给出可被读者感知的异常反应或观察点，并在写作报告标注”伏笔型认知异常”。
10. 每章写完后做一次叙述者认知边界自检：新场景、新地点、新身份、时代背景等确定标签，叙述者是否在角色通过观察、感官、证据或推断确认后才给出。场景切换后严格按”观察→临时称呼/感官描述→积累证据→推断并确定标签”的顺序写。典型违规：角色刚到陌生空间，叙述者直接写”一间丧铺””一家民国时期的当铺”——这是叙述者越过了角色的认知边界，属于角色认知链问题的叙述者侧扩展。

输出：

- 章节正文。
- 简短写作报告：章节字数、关键情节、技法落点、红线避让点、动作与道具状态自检结果、有意重复动作说明（如有）、本章新增术语/认知变化（如有）、角色认知链自检结果（如有异常知情需标注）。
- 对当前执行包的偏离：无 / A-B级记录 / C-D级需主 agent 分级反馈。
- 下一批执行包：不处理，交主 agent。

## polisher

职责：批量章节润色师。

必须读取：

- style-guide、characters。
- 当前入口和 active 当前执行包。
- 待润色章节。
- 本批次技法包和 content-writer 写作报告。
- 当前卷术语认知状态表（若存在）。
- 写作红线规范。

必须执行：

1. 只改语言表达，不改事件顺序、人物动机、世界观规则和技术结论。
2. 检查技法是否真正落地：打斗是否有距离/节奏/代价，推理是否有证据链，恐怖是否有氛围递进，商战是否有筹码变化。
3. 强化句式、动词、视角、道具功能化、章末钩子。
4. 删除或改写触碰红线的具体联系方式、网址、真实平台、可复现攻击步骤、血腥色情细节。
5. 逐章扫近距重复表达：重复词、重复句式、重复动作描写都要标出；如果重复动作造成状态矛盾，不能只当语言问题，必须在报告里交给 outline-checker 或主 agent 复核。
6. 不要机械删除有意重复动作。若重复动作用来表达纠结、迟疑、压抑、强迫确认或情绪升级，且每次重复都有停顿、缩回、换对象、生理反应、环境反馈或动作幅度变化，应保留并可微调为更清晰的递进。
7. 检查术语认知与设定泄露：角色在首次知晓世界观/系统术语之前，不应使用该术语定义处境；新术语应有角色知晓方式和正文证据；未知术语改为可感知细节、临时称呼或推测语气。
8. 检查角色认知链：称呼、姓名、身份、关系、旧事、地点、规则、道具来源和他人行动是否有信息来源；无来源且非伏笔时，优先改成中性称呼、补一句信息交接，或交给主 agent 判断是否需要结构性修复。若是伏笔型异常知情，应保留并强化 POV 或叙述者对异常的捕捉。
9. 检查叙述者认知边界：新场景、新地点、新身份、时代背景等确定标签是否在角色通过观察和推断后才出现。场景切换段落若出现"一间丧铺""民国时期的当铺"等提前标签，改为感官描述→临时称呼→推断→确定标签的顺序。这是角色认知链在叙述者侧的扩展——叙述者不能替角色越级认知。

输出：

- 覆盖润色后的章节。
- 润色报告：每章主要处理了什么，技法落地是否增强，重复表达/重复动作是否处理，有意重复动作是否保留，术语认知/设定泄露是否处理，角色认知链是否发现或处理异常，红线是否处理。
- 结构性反馈候选：无 / 更新状态表 / 反馈上游；不生成下一批执行包。

## outline-checker

职责：批量大纲/卷纲/章纲审查员。

注意：outline-checker 不配置写作技法，不评价“文笔是否好看”。它只负责对应、连续、合规、伏笔、事实一致，以及动作与道具状态、角色认知链是否自洽。动作重复导致的状态矛盾、角色认知越界和信息来源缺失都属于事实连续性问题，不属于可忽略的文笔问题；但有意重复动作如果服务人物纠结、迟疑、压抑、强迫确认或情绪升级，且有明确递进或状态变化，必须标为“有意重复，保留”，不得机械拦截。

普通批次必须读取并细读：

- 当前入口和 active 当前执行包。
- 待审查章节全文。
- 术语、角色、关键道具和伏笔状态相关行。
- 当前卷术语认知状态表（若存在；本卷首次批次可由主 agent 创建后复核）。
- 写作红线规范。

发现当前执行包硬点缺失、偏移或状态不明时，再读取对应章纲段和当前卷纲相关段。全书大纲只在新项目、新卷开始、跨卷批次、卷末审查、跨卷审查、卷纲明显偏离，或当前卷材料无法回答伏笔/终局/人物状态问题时读取。

必须执行：

1. 逐章建立“当前执行包硬点 -> 正文证据”的对应表；发现偏移时再升级为“章纲条目 -> 正文证据”。
2. 章纲有但正文没有：标记遗漏。
3. 正文有但章纲没有的大事件：标记新增偏离，判断是否需要回写 memory 或修改正文。
4. 检查时间线、人物行为、术语、世界观规则、伏笔、红线。
5. 对每章做“近距动作与道具状态检查”：重点扫相邻5-10段内的不可重复动作、关键道具状态、人物姿态、伤势位置、战斗后收束动作。典型问题包括：已收刀又收刀、未取出却再次收起、未放下却再次拿起、已坐下却再次坐下、已站起却仍靠坐、伤口位置前后变化、门窗/棺板/武器已损坏却继续完整使用。
6. 对重复动作先分类再下结论：
   - 状态矛盾：无中间状态变化却重复完成不可重复动作，标红或标黄并要求修复。
   - 冗余重复：不造成状态矛盾，但没有心理、节奏或信息增量，标黄建议压缩。
   - 有意重复：用于表达纠结、迟疑、压抑、强迫确认、情绪升级、仪式感或规则压迫，并有停顿、缩回、换对象、生理反应、环境反馈、动作幅度变化或选择后果，标绿保留。
7. 报告中写明判定依据，不允许只凭“重复”二字要求删除。
8. 对每章做“术语认知与设定泄露检查”：对照术语认知状态表和正文证据，确认角色首次知晓前未使用正式术语；本批新增术语必须有章节、角色、知晓方式和证据；若表缺失或需更新，报告给主 agent。
9. 对每章做”角色认知链检查”：确认角色说出的姓名、称呼、身份、关系、旧事、地点、规则、道具来源、他人行动都有前文来源或身份自带知识。重点查首次见面直接叫姓名/亲密称呼、提前知道隐藏身份、未听闻却复述旧事、无依据判断道具来源等问题。
10. 对每章做”叙述者认知边界检查”：场景切换、新地点登场、新身份揭晓时，叙述者是否在角色通过观察和推断后才给出确定标签。典型违规：角色刚进入陌生空间，叙述者直接写”一间丧铺””民国时期的当铺””一个旧书铺”——确定标签必须放在感官证据链之后，按”观察→临时称呼/感官描述→证据→推断并确定标签”顺序。此项是角色认知链在叙述者侧的扩展。
12. 对认知链问题（含角色认知链和叙述者认知边界）先分类再下结论：
   - 信息来源缺失：无前文获得路径却说得像已知事实，标黄或标红并要求修复。
   - 轻微表达误导：读者会卡顿但不影响主线，建议改成中性称呼、模糊判断或补一句信息交接。
   - 伏笔型异常知情：角色异常知道某事是刻意设计，正文有 POV 捕捉或叙述提示，并有后续回收窗口，标绿或黄并记录追踪。
   - 场景标签前置/叙述者认知越界：角色尚未通过观察和推断确认场景/地点/身份，叙述者已给出确定标签，标黄或标红并要求修复。修复方式：将确定标签移到感官证据链之后，或改为感官描述/临时称呼/推测语气。
13. 每章输出独立报告，并汇总红色问题。

单章报告模板：

```markdown
# 校对报告 · 第{XXX}章：{标题}

## 章纲对应表
| 章纲条目 | 正文对应位置/证据 | 覆盖状态 | 偏差 | 严重度 |
|----------|-------------------|----------|------|--------|

## 连续性检查
## 动作与道具状态检查
## 术语认知与设定泄露检查
## 角色认知链检查
## 人物与设定检查
## 伏笔追踪
## 红线检查
## 问题清单
## 结论
```

严重度：

- 红色：必须修复，否则不能进入下一批。
- 黄色：建议修复或请用户定夺。
- 绿色：伏笔记录、优点、已覆盖项。

## 主 agent

主 agent 是主编，不等同于 outline-checker。

必须执行：

- 调度写作、润色、审查。
- 做跨章审查和跨卷审查。
- 复核 outline-checker 的动作与道具状态检查结果；跨章终审时抽查关键人物、关键道具和伤势的状态链，同时保护有意重复动作。
- 更新或确认当前卷术语认知状态表：本卷首次批次创建，后续批次追加新术语、认知变更和设定泄露修复结果；本批无新增也要在批次记录中说明。
- 复核角色认知链：抽查首次见面、称呼变化、身份揭露、旧事提及、地点/道具来源和隐秘行动知晓链；无来源的异常知情必须修复，或明确标为待回收伏笔并记录回收窗口。
- 复核叙述者认知边界：抽查场景切换和新地点登场段落，确认确定标签在感官证据链之后才出现；提前标签必须修复。
- 修复红色问题。
- 更新进度和 memory。
- 输出 A/B/C/D 下游反馈单；需要继续时调用上游规划口径生成下一批当前执行包。
- 将下一批 active 当前执行包登记到项目当前入口；未完成登记时不得继续写作。
- 每批结束并生成执行包后暂停，等待用户检查。
