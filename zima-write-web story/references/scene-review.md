# 场景审读与盲读

## 相邻几场读来一样时

并排读相邻两三场。每场开头读者在等什么答案？人物在哪一句松口、拒绝或改作决定？读者何时知道答案？若人名、证物都换了，却总是先否认、见物证、松口、再由旁白总结，选一处改法试读。可以提前让人开口，或让他坚持拒绝，由下一场接过这个问题。核对关键线索、原有的抵抗和已发生的动作：省掉第三句“她记下了”之前，先查后文是否用到她的笔记。只授权改表达时，涉及动机或知情顺序的改法留作意见。

需要细看时，只摘段首、转场和关键台词，找到重复具体发生的地方。连载回顾、仪式、口头禅常有独立作用。三次点名中，母亲替大女儿答，二女儿自己答，小儿子的碗前无人答。前两声使最后的沉默有分量，三轮可以原样保留。

## 关键揭晓需要验证阅读时点时

1. 主审私下记下章纲预期，以及允许读者先猜到哪些事。给未看过章纲、答案和后文的独立读者一段连续正文，停在揭晓前。此前必要线索随正文提供。
2. 中性地问“读到这里，你暂时怎么理解？哪句话让你这样想？还有什么拿不准？”先保存这次回答，再发送连续后文。第二轮问哪些原判断得到印证、改变或仍不确定。别把目标嫌疑人、作者意图或怀疑方向塞进问题。
3. 主审把两次判断与预期并排，引用改变读法的原句。区分“读者有可能猜到”与“正文已经说出答案”，也区分人物的主张与已证实事实。正常交接或作者有意早揭的场面，可以保留。需要挪动既定揭示窗口时走已有反馈流程。

没有隔离读者或完整前文时，标为知情审读或材料有限，只记录能核查的线索。已知结局后回想的意见不能充当首次阅读记录。盲读仅在揭晓、误导或重要知情差值得复查时使用。

这些按需方法据 [Sepia v0.13.0](https://github.com/Nanako0129/sepia/tree/v0.13.0) 的小说结构、审读和风格自校思路，按中文连载与 Zima 分工重新表述。可用已安装的 Sepia 单独征求第二意见，交主审核对权限与本书事实。作者声音以本书为据，句长、标点频率和“AI 率”均不能证明改稿有效。
