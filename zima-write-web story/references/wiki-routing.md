## 必读导航

每次处理新项目或新类型，先读：

- `index.md`：全局索引，用 `rg` 定位相关模块。
- `话题/00-素材库导航.md`：拆书轨、创作轨、标签轨说明。
- `话题/标签/00-标签导航.md`：标签聚合入口。
- `话题/标签/_taxonomy.md`：标签关系。
- `话题/方法论/00-类型导航.md`：写作技法、结构技法、文本细读入口。

常用命令：

```powershell
rg -n "关键词1|关键词2|关键词3" "D:\knowledge base\zima-fiction\wiki\index.md"
rg --files "D:\knowledge base\zima-fiction\wiki" | rg "关键词1|关键词2"
```

## 场景元素借鉴

### 拳拳到肉的打斗

检索：

```powershell
rg -n "鲁提辖拳打|醉打蒋门神|景阳冈|拳|擂台|以伤换命|老拳师|BOSS战|数据化战斗" "D:\knowledge base\zima-fiction\wiki\index.md"
```

借鉴方式：

- 拆目标：谁要逼谁先动、谁在保留底牌、谁在争取时间。
- 拆节奏：试探、错位、短暂失衡、代价、反击。
- 拆环境：桌椅、雨水、灯光、地面、围观者，必须参与战斗。
- 写身体反馈，但避开血腥细节和暴力美化。

### 推理解密

检索：

```powershell
rg -n "推理|侦探|线索|证据|凶手|内奸|逻辑链|误导|排除|审判" "D:\knowledge base\zima-fiction\wiki\index.md"
```

借鉴方式：

- 至少有可回看证据，不靠灵感破案。
- 设计一条误导链和一条反证链。
- 揭秘时每个结论都对应前文物证、行为或语言。
- 高潮尽量让真相改变人物关系或局势，而不只是解答谜题。

### 灵异恐怖

检索：

```powershell
rg -n "恐怖|灵异|志怪|画皮|僵尸|歌谣|封闭空间|恐惧具象化|怪谈" "D:\knowledge base\zima-fiction\wiki\index.md"
```

借鉴方式：

- 从日常物异常开始，不急着露怪。
- 用空间限制、声音、气味、重复句式和信息缺口制造不安。
- 让线索本身带恐怖感，例如歌谣、旧档案、损坏的监控。
- 不宣扬真实迷信，不使用真实邪教名称。

### 商战/科技攻防

检索：

```powershell
rg -n "AI|科技|数字生命|意识共振|赛博朋克|权谋|博弈|心理战|垄断|数据|合规" "D:\knowledge base\zima-fiction\wiki\index.md"
```

借鉴方式：

- 把“打斗”转译成信息差、资源差、合规边界、舆论窗口和技术瓶颈。
- 对手不是愚蠢，而是基于旧优势做出合理误判。
- 技术描写写现象和影响，避免可复现攻击步骤。
- 会议和谈判必须有筹码变化，不能只是观点陈述。
