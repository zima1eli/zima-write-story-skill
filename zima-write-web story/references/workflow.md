# 正文批量写作工作流

默认粒度：普通推进约10章；高密度推理或规则释放约5章；卷末高潮1-3章，写完即审。用户指定范围优先，但出现卷末、跨卷、红色问题或核心设定集中释放时，主 agent 应说明原因并升级模式。

## Step -1：迁移接管

仅在已有正文接入新流程时执行：

1. 把已写正文当作事实基线，提取人物、关系、道具、术语、角色认知、伏笔和风险实绩。
2. 用正文事实反校旧规划，按 A/B/C/D 分级：A只记录，B更新状态，C修订后续输入，D暂停并修复系统冲突。
3. 不因新流程机械重写旧章节；只有红色硬伤才回修正文。
4. 更新当前入口、实绩基线和状态表后，生成当前执行包。

## Step 0：范围与交接检查

1. 确定起止章、卷号、卷名、章节输出目录。
2. 读取 `00-CURRENT.md` 或等价当前入口，确认有效正文范围、当前执行包和废弃口径。
3. 读取当前执行包，确认其为 active，且包含硬门、软门、分章施工卡、回读触发器和写后覆盖表。
4. 按 `references/handoff-contract.md` 检查上游交接包。
5. 查看项目进度和报告索引，确认上一批没有未修复红色问题。
6. 判断迁移接管档、标准批次档、标准加强档或严格审查档；红色问题先修复并复查。

## Step 1：技法包与红线预审

1. 按当前卷、章纲元素和 `references/wiki-routing.md` 刷新技法包。
2. 对每章标注元素：动作、推理、恐怖、商战、情感、规则、群像等。
3. 每章指定 1-3 个可落地技法。
4. 读取项目红线规范，列出本批风险点。

## Step 2：初稿写作

有项目 `content-writer` 时复用；没有时主 agent 本地执行同等流程。

每章目标：

- 字数服务情节，不设固定字数目标；也不能把冲突、推理、动作、选择、代价或高潮压成剧情摘要。
- 章节应让读者完整经历进入局面、可感知证据、阻力变化、人物反应或误判、主角选择、代价或状态改变、余波或章末推进。缺少必要过程时，视为情节容量不足。
- 短章只用于余波、过桥、冷钩子、单点反转或节奏换气；无法说明短章功能时，应补足现场、证据链、动作、选择与代价。
- 从冲突现场或信息中段切入，少写无戏剧性的交通、起床、进门。
- 相邻场景能用“因此/但是”连接。
- 规则或技术首次出现时，用感官、代价或现象落地，不写教科书说明。
- 章末必须有钩子，连续三章不要重复同一种钩子。
- 每章写完记录技法落点、红线避让、动作与道具状态、新术语认知、角色认知链和下一章注意。

## Step 3：润色

有 `polisher` 时复用；没有时本地处理。

润色只改表达，不改情节结构。重点检查：

- 重复词、弱动词、废话过渡、解释性对话。
- 近距重复动作及是否造成状态矛盾。
- 视角越界、术语不一致、术语提前暴露。
- 角色认知链：姓名、称呼、身份、关系、旧事、地点、规则、道具来源和他人行动是否有信息来源。
- 技法是否真的进入文字，而不是停在计划里。
- 红线风险是否被模糊化、虚构化、结果化处理。

## Step 4：校对

有 `outline-checker` 时复用；没有时本地输出校对报告。

逐章对照：

- 当前卷纲中的本批段落目标。
- 当前书写章节的单章章纲条目。
- 人物行为、时间线、世界观规则、伏笔。
- 术语认知状态与角色认知链。
- 动作与道具状态。
- 红线。

报告必须按红 / 黄 / 绿分级。红色问题必须修。

## Step 5：主编跨章终审

主 agent 亲自复核：

- 时间线连续性。
- 动作与道具状态。
- 术语认知与设定泄露。
- 角色认知链。
- 人物连续性。
- 情节线与卷纲弧段。
- 伏笔交叉验证。
- 节奏与钩子变化。
- 红线复查。
- 下一批风险。

主 agent 完成终审和 A/B/C/D 分级后，若需要继续写作，必须调用上游规划口径吸收正文实绩，生成下一批当前执行包并登记为 active。content-writer、polisher、outline-checker 不得生成或登记下一批执行包。

## Step 6：跨卷审查

仅在卷结束、卷开始、跨卷批次或大纲偏离风险时执行。

读取上一卷、当前卷、下一卷的目标，卷间状态，跨卷伏笔，卷末/卷首章节和上一批审查报告。确认卷目标、人物状态、组织/资源状态、伏笔窗口、情绪收束、世界观规则和红线风险是否完成交接。

## Step 7：记录进度

每批结束更新项目进度或 memory：

```markdown
## 第{N}-{M}章批次 · {YYYY-MM-DD}

- 状态：
- 章节：
- 卷：
- 技法包：
- 关键剧情：
- 章纲覆盖：
- 红色问题：
- 黄色建议：
- 伏笔变化：
- 术语认知：
- 角色认知实绩：
- 下游反馈单：
- 下一批风险：
- 下一批当前执行包：已生成并登记 / 暂停，等待上游修订
```

未生成并登记下一批 active 当前执行包时，流程停在主 agent，不得交给 content-writer 开写下一批。
