# 当前执行包与偏移处理协议

## 原则

大纲是规划源，当前执行包是批次缓存，正文是已发生事实，审查负责校准。普通写作的目标不是读取最多资料，而是在最小必要上下文里保持人物、因果、伏笔、设定和读者体验连续。

## 默认工作集

1. 项目当前入口。
2. active 当前执行包。
3. 前1-2章正文和本章草稿/目标。
4. 术语、角色、关键道具和伏笔状态的相关行。
5. 项目风格、红线和本批专项要求。

默认不通读全书大纲、当前卷纲全文、旧报告、归档、备份或完整 wiki。小偏差回读对应章纲段；结构风险回读卷纲相关段；卷末、跨卷、红色问题或核心规则冲突才读取全书材料。

## 当前执行包

当前执行包在上一批终审、状态更新和 A/B/C/D 反馈吸收后生成，是下一批开工许可证。至少包含：当前事实、批次目标、执行模式、分章施工卡、硬门、软门、回读触发器、写后覆盖表和反馈格式。

出现 C/D 级偏移、用户改方向、重跑章节、卷末/跨卷接续或状态重大变化时，当前执行包失效，必须重新生成。未登记 active 执行包时，下一批暂停。

## 偏移分级

| 级别 | 判断 | 动作 |
|------|------|------|
| A | 表达方式变化，不影响目标 | 记录 |
| B | 正文自然改变状态 | 更新术语、角色、道具、伏笔或风险 |
| C | 后续规划必须吸收 | 暂停下一批，修订执行包或章纲 |
| D | 破坏卷级目标、核心规则、人物关键动机或伏笔窗口 | 暂停正文，回上游重审 |

不默认正文错，也不默认规划错。先问：这处变化是否更符合人物、因果、伏笔和读者体验，且不破坏卷级硬目标？
