# 上游规划 harness

第一性原则：上游把未来正文的不确定性压缩成可执行交接包；下游执行、记录正文实绩并反馈。项目初始化、来源标记、成熟度、包版本与更新顺序以 `project-initialization.md` 为准。

## 适用范围

- 新建或优化卷纲、章纲与章节技法包。
- 根据既有正文接管项目状态。
- 按需生成卷级接口卡、本批输入包和首批/续批当前执行包。
- 做单卷或跨卷接口审查。
- 吸收下游反馈，修订下一批或下一卷规划。

## 0. 既有正文接管

当前卷已有正文时，读取相关已写章节、当前卷纲/章纲、当前入口、项目进度和审查报告，核实接受状态后建立实绩基线；未审内容单列。记录已写范围与关键剧情，并按内容需要记录人物与关系、伤势/资源、道具、认知、伏笔和风险。

旧计划与正文实绩不一致时：

| 级别 | 处理 |
|------|------|
| A | 只记录，不改规划 |
| B | 更新状态表、接口卡或风险记录 |
| C | 修订下一批章纲、输入包、材料层、认知路径或伏笔窗口 |
| D | 暂停正文，先修卷纲、核心设定或旧文红色问题 |

优先修订后续规划；已接受的旧正文只在 D 级硬伤时建议回修。当前待审稿的局部修复仍按审查意见处理，不受这条旧文保护规则阻挡。

## 1. 单卷规划

卷纲回答：本卷为什么非读不可；起点、终点、高潮、代价和回报点是什么；核心阻力如何升级；人物的核心信念或行动逻辑如何被事件持续碰撞。涉及伏笔、术语、规则或身份信息时安排释放；有下一卷时设计状态接口，无卷划分时按实际叙事段规划。

## 2. 章纲施工图

达到可直接扩写深度的章纲包含：目标、冲突、必要条件、场景节拍、转折、钩子或收束、足以支撑本章的技法及落点（通常 1–3 项，不机械凑数）、可写材料层。认知路径、关键道具和伏笔窗口按本章内容补齐；不适用时说明，不编造系统术语或关键道具来填表。

可写材料层只写物象、动作、对白遮掩、误读/错认、题材细节和节奏提示等短条目；不代写正文，不给完整对白。

## 3. 卷级接口卡

```markdown

- 关键道具：

## 卷内变化
- 人物与关系变化：
- 道具变化：

## 卷末输出

- 关键道具：

```

## 5. 跨卷接口审查

有跨卷依赖时，对照前卷接口卡、当前卷规划和必要的已接受正文，检查实际涉及的人物、关系、资源、道具、认知、伏笔和主线承接。零正文时做规划接口审查；正文卷末及跨卷实绩审查见 `review-and-progress.md`，二者不能相互冒称。

## 6. 下游反馈吸收

按 A/B/C/D 处理下游反馈；同类黄色问题连续出现两次以上，检查是否存在系统缺口。确实影响后续规划时升级 C；只涉及表达的复发可刷新技法或润色指引，不因次数直接断言章纲有错。分级依据是实际影响，处理和复核结果仍须记录。

## 7. 当前执行包

它是按最新事实校准的开写快照，不等于输入包。零正文首批从已审规划与初始状态产生，续批在终审、实绩入账和后续规划修订后产生；具体字段、状态转换、唯一入口及失效规则见 `project-initialization.md` 第 5—7 节。没有下一批任务时不生成空包。
