# zima-fiction 方法论路由

知识库根目录：

```text
D:\knowledge base\zima-fiction\wiki
```

只使用本库 `wiki/`，不要访问 `D:\knowledge base\zima-ai`，也不要为了创作卷纲/章纲读取 `raw/`。

## 检索入口

优先读：

- `话题/方法论/00-类型导航.md`
- `wiki/index.md`
- `话题/标签/00-标签导航.md`
- `话题/方法论/写作技法/`
- `话题/方法论/结构技法/`
- 对应题材的 `话题/<类型>/结构技法/`、`情节与母题/`、`大纲/`

常用命令：

```powershell
rg -n "大纲|章纲|期待感|钩子|伏笔|冲突|节奏|代入感" "D:\knowledge base\zima-fiction\wiki\index.md"
rg -n "关键词1|关键词2|关键词3" "D:\knowledge base\zima-fiction\wiki\话题\方法论" -g "*.md"
```

```markdown
## 技法包

  - 话题/方法论/写作技法/大纲创作法.md
  - 话题/方法论/结构技法/准确的钩子.md
- 卷级应用：
  - 本卷用“高潮逆推”确定终局
  - 中段用“计划-意外循环”制造连续升级
- 章节应用：
  - 第001章：从冲突现场切入，语言钩子结尾
  - 第002章：用侧面信息差强化期待感
- 风险：
  - 不写正文对白
  - 不堆技法名
  - 不让钩子脱离核心阻力
```
